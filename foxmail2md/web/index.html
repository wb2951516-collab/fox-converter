使用说明

导入存档

点左下角「导入 .fox 文件」，选一个或多个 .fox，也可以直接选文件夹。大文件要跑几分钟，进度条会动。第一次用的话，先把设置里的存储位置改到空间够的盘。

看邮件

左侧点一封，右边看正文。正文有三种看法：原文（和 Foxmail 里一样）、Markdown、纯文本，右上角切换，旁边有复制按钮。有附件的邮件会多一个「附件」页，进去能单独下载。

搜索和分组

搜索框输入关键词，主题、发件人、正文都能搜到，中文没问题。「分组」下拉可以把同一件事的来往邮件归到一起（按主题），也能按发件人、收件人分。

清理空间

「查找清理」页按发件人、主题、日期、大小把邮件筛出来，勾选后删除。删法有两种：只从列表移出（文件留着），或者连文件一起删掉腾空间。删之前会再让你确认一次，删掉的内容重导对应的 .fox 就能找回来。

存储位置

设置页里两样东西可以换地方：存档数据（数据库）和导出文件（MD/纯文本/附件）。改成想要的盘，点「迁移到新位置」，文件会自动搬过去，旧位置清空。以后导入的都存到这里，不会再写 C 盘。

Agent 接入

「Agent 接入」页复制两段内容发给智能体（比如 WinClaw 小龙虾）：先发提示词装技能，再发 Key 完成配置。之后直接跟它说"查一下某某的邮件"就行。
