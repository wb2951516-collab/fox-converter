# Foxmail `.fox` 存档文件格式（逆向分析报告）

## 概述

Foxmail 7.x 的「邮件存档」功能生成 `.fox` 文件。该格式为 Foxmail 专有容器，**邮件内容以明文 RFC822 MIME 存储，未加密**。

## 文件结构

```
┌─────────────────────────────────────────────────┐
│ 文件头                                          │
│   魔数: b'ARCF' (4B)                            │
│   版本: uint32 LE (0x00000001)                  │
│   GUID: 16B                                     │
│   索引/元数据区 (~27MB，含邮件偏移索引等)       │
├─────────────────────────────────────────────────┤
│ 邮件记录 × N                                    │
│   ┌────────────────────────────────────────┐    │
│   │ 16 字节邮件魔数 (见下)                 │    │
│   │ RFC822 MIME 明文 (CRLF 换行)           │    │
│   │ UTF-16LE 尾部元数据 (不影响 MIME 解析) │    │
│   └────────────────────────────────────────┘    │
└─────────────────────────────────────────────────┘
```

## 邮件记录魔数

```
10 10 10 10 10 10 10 11 11 11 11 11 11 53 0D 0A
```

16 字节固定魔数，每封邮件前出现一次。在 1.18GB 样本中验证：**1108 个魔数全部为真记录，0 误命中**（魔数后紧跟 `Received:` / `Return-Path:` 等合法邮件头）。

## 邮件内容

- 标准 RFC822 MIME 格式，CRLF 换行
- 头部含 `Received:`、`Return-Path:`、`Message-ID:`、`From:`、`Subject:`、`MIME-Version: 1.0`、`Content-Type` 等
- 中文 Subject/From 使用 RFC2047 编码（`=?gbk?B?...?=` 或 `=?gbk?Q?...?=`）
- `X-Mailer: Foxmail 7.2.25.563[cn]` 标识来源
- 正文 multipart，附件 base64 编码
- 邮件间尾部有 UTF-16LE 元数据（Foxmail 渲染预览/索引），在 MIME final boundary 之后，不影响 Python `email` 库解析

## Carve 策略

1. mmap 打开 `.fox` 文件
2. 顺序查找 16 字节魔数，记录全部偏移
3. 第 i 封邮件 = `mm[magic[i]+16 : magic[i+1]]`（末封到 EOF）
4. 交由 Python `email.message_from_bytes(raw, policy=email.policy.default)` 解析

## 性能特征（1.18GB 样本）

- 邮件数: 1108
- 块长: min=1.7KB, median=260KB, max=40.8MB
- >1MB 的邮件: 261 封（含大附件）
- mmap 流式遍历，单封加载内存峰值 = 最大邮件块(40.8MB)
